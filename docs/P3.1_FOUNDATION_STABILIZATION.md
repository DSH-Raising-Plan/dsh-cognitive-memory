## 冻结范围（不得在本阶段扩张）

已接受能力（Foundation Verified）：

- Universal Data Model 基础 Schema
- Component Contract 基础校验
- 外部 REST 组件注册与 Discovery
- PCIP 基础交换流程
- L3 默认拒绝
- L1 内容进入 Observation
- 外部内容不自动晋升为 Active Memory
- 过期、错误目标节点和权限边界拒绝

Partial / Planned **保持原状**，稳定化过程中不得悄悄扩大承诺。
